## Struktur Fungsi
Program menggunakan fungsi untuk memisahkan tugas menjadi bagian-bagian kecil. Parameter digunakan untuk menerima masukan, `return` untuk mengembalikan hasil, dan scope menentukan lingkup variabel.
## Hasil Pengujian
| Pengujian | Input | Hasil |
|---|---|---|
| Luas persegi panjang | 8 dan 5 | 40.0 |
| Luas segitiga | 10 dan 6 | 30.0 |
| Jumlah 1 sampai n | n = 10 | 55 |
